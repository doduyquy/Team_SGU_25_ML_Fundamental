**New Tools:**
- `lazy_show()` - Delayed rendering
- `batch_show_figures()` - Multi-figure optimization
- `optimize_figure_for_performance()` - Remove animations, reduce points
- `set_plotly_renderer()` - Use efficient renderer
- `show_minimal()` - Minimal UI mode

**Example:**
```python

```

## 🚀 Quick Start

### Step 1: Update Your Notebook Setup

Replace your old setup:
```python
# Old (v2.0)
from utils.display_tools import setup_notebook_style

```

With the new enhanced setup:
```python

```

## ⚡ Performance Tips

### For Large Datasets

```python
# Enable performance mode
setup_notebook_style(theme="light", performance_mode=True)

# Use efficient renderer
from utils.display_tools import set_plotly_renderer
set_plotly_renderer("notebook_connected")
```

### For Multiple Plots

```python
from utils.display_tools import batch_show_figures

# Create your figures
figures = []
for col in df.columns[:10]:
    fig = px.histogram(df, x=col)
    figures.append(fig)

# Render efficiently
batch_show_figures(figures, delay=0.15, performance_mode=True)
```

## 🔧 Customization

### Create Your Own Theme

1. Create a JSON file:
```json
{
  "my_theme": {
    "name": "My Custom Theme",
    "plotly_template": "plotly_white",
    "primary_color": "#FF5733",
    "secondary_color": "#C70039",
    "font_family": "Arial, sans-serif",
    ...
  }
}
```

2. Load your theme:
```python
from utils.theme import VisualizationTheme

theme = VisualizationTheme(
    theme="my_theme",
    config_path="my_theme.json"
)
theme.apply_theme()
```
